# Administration
## Description
Those projects were made for Administration and Project Management classes. They aren't directly programming related, but rather, to multiple soft skills designed to enable programmers to communicate properly with a client, understand their needs and the needs of the company.
## Soft Skills
- Management: Being able to work with multiple people to design a solution where everyone needs to be an essential part of it, while making sure everything works well.
- Planning: Creating action plans to address key issues of a company by using known methodologies like PMBOK.
- Presentation: Making complex/elaborate ideas into simple-to-explain, visual-aligned documents.
